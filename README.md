# Every Wonderful Dream

An interactive atlas of every Small Tract Act ("jackrabbit") homestead in the San Bernardino County desert:
the land in 3D, the survey that drew it, and the patent that made it somebody's. The name comes from
Wonder Valley, California.

## What's here

| Page | What it does |
| --- | --- |
| `/` | Dusk flyover of Wonder Valley, the numbers, patents per year, featured places, an annotated patent |
| `/atlas/` | Full-screen 3D map of all tracts with search, layers (survey grid, classified land, color by year, topo) |
| `/tract/?id=CALA-0060931` | One page per tract: orbiting 3D view, facts, patent abstract, section and township diagrams, neighbors, research links |
| `/names/` | Searchable A–Z patent index, name rankings, and same-surname clusters |
| `/places/` | The communities, each drawn as a dot map of its tracts |
| `/history/`, `/resources/`, `/about/` | The story, other people's work, sources and method |

It is a static [Astro](https://astro.build) site. Maps are [MapLibre GL JS](https://maplibre.org) over
public-domain USGS imagery and open terrain tiles; no API keys are needed.

## Run it

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # static site in dist/
npm test           # unit tests for the legal-description parser, date estimator and name formatter
```

After building, run `node tests/names-page.browser.mjs` to check the Names rankings and search in Google Chrome.

## The data

Everything under `public/data/` is generated. To rebuild it from the sources:

```bash
npm run data:harvest            # BLM Small Tract cases for California -> data/raw (about 15 minutes, cached)
node scripts/harvest-context.mjs  # PLSS section outlines + elevation tiles for the townships that have tracts
# optional, only to regenerate data/foia-small-tract.json from the original spreadsheets:
#   download snbdo01-04.zip from https://vredenburgh.org/capatents/ and unzip into data/raw/vredenburgh/xls, then
#   uv run --with xlrd python -I scripts/import-foia-patents.py data/raw/vredenburgh/xls data/raw/vredenburgh/patents.json data/foia-small-tract.json
npm run data:build              # data/raw -> public/data
```

| Source | Used for |
| --- | --- |
| BLM MLRS Land Tenure Case layer, product `SMALL TRACT` (`nlsdbpubgis.blm.gov`) | Every tract: outline, legal description, serial number, patent number |
| BLM National PLSS CadNSDI (`gis.blm.gov`) | Section outlines |
| Census county boundary via BLM (`gis.blm.gov`) | Clipping to San Bernardino County |
| AWS Terrain Tiles (Mapzen) | Elevation at each tract; 3D terrain in the browser |
| USGS The National Map, USDA NAIP | Imagery and topo, served live |
| BLM's California patent index, FOIA 1997, published by Larry Vredenburgh (`vredenburgh.org/capatents`) | Patentee names and patent dates for 20,954 tracts, joined by patent number (`data/foia-small-tract.json`) |
| BLM GLO Records (`glorecords.blm.gov`) | The scanned patents (linked from every tract); details checked by hand go in `data/patents-verified.json` and override the index |

Hand-maintained inputs:

- `data/places.json`: the gazetteer of communities (center point and radius) tracts are assigned to.
- `data/foia-small-tract.json`: the Small Tract rows of BLM's patent index (`d` patent number, `c` case serial,
  `t` date, `n` names as indexed, surname first). Generated by `scripts/import-foia-patents.py`.
- `data/patents-verified.json`: patent details read from GLO Records, keyed by patent number:
  `{ "1135268": { "names": ["Ruth Sem"], "date": "1952-05-23", "image": "patents/1135268.jpg", "source": "…" } }`.
  `image` is optional and is a path under `public/`. Add entries here and re-run `npm run data:build`.
- `scripts/lib/patent-dates.mjs`: the anchor table used to estimate a patent's year from its number.

### Known gaps

- **Patent images** are not hosted: the GLO Records site (relaunched in 2026) has no bulk download, so each
  tract links to its patent there. Add an `image` in `data/patents-verified.json` to show one.
- **Names** come from an index that is upper-case, surname-first and truncated at 30 characters;
  `scripts/lib/names.mjs` reorders them by rule. 34 tracts have no index entry.
- **Dates** for those 34 are estimated from patent numbers (the estimate matches the indexed year 96.7% of
  the time across 20,309 patents).
- About 225 tracts (mostly numbered lots) are located only to their section because that is all BLM's
  geocoding provides. Another 261 with ordinary aliquot descriptions have outlines derived in `build-data.mjs`
  by subdividing the section between its corners (checked against BLM's mapped tracts: median error about 1 m).

## Layout

```
scripts/        harvest + build pipeline (plain Node ESM)
scripts/lib/    legal-description parser, patent date estimator, name formatter (shared with the site)
data/           hand-maintained inputs; data/raw is the harvest cache (git-ignored)
public/data/    generated: summary, tract outlines, per-township records, search index
src/lib/        map setup, data loading, formatting
src/pages/      the site
tests/          node --test
```
